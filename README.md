## About

This is a clean, modern, and bilingual (Portuguese / English) portfolio built as a single-page static website.  
It showcases professional experience, undergraduate research in graph theory, technical skills, and projects.

### Features

- Fully bilingual (PT-BR / EN) with language switcher
- Dark theme optimized for readability
- Responsive design (mobile-first)
- Smooth scroll navigation
- Sticky header
- Contact form integrated with Formspree
- Lightweight — pure HTML, CSS, and vanilla JavaScript (no frameworks)
- Fast loading and accessible

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/LuizFernando2-prog/portfolio.git
   ```

2. Open `index.html` in your browser  
   or use a simple local server:

   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js (if you have npx)
   npx serve .
   ```

3. Access: [http://localhost:8000](http://localhost:8000)

## Deployment

Recommended platforms for this static site:
